This reference means **CIIC / Zhongzhi consulting color style only** by default. Keep the CIIC-inspired blue, pale-blue, white, charcoal, and small orange-red accent system, but do not copy the source PPT template layout unless the user explicitly asks for full template replication.

## When To Use

- Chinese management consulting reports, proposal decks, research briefings, SOE/corporate governance topics, organization control studies, and executive presentations.
- User mentions Zhongzhi/CIIC template style, blue consulting style, attached PPT template style, or gives no other visual style for a Chinese consulting deck.
- Default visual direction for this skill's Chinese consulting decks unless the user specifies another style.

These assets are color references only. Do not preserve their title bars, page footers, page-number markers, logo placement, city/building motifs, catalog layouts, closing page, or bottom slogan strips unless the user explicitly requests full template reproduction.

The business-blue framework templates are structure references only. Use their framework grammar when it matches the report logic, but do not copy placeholder text, QR codes, logos, instruction pages, unrelated decorative elements, or original template color styling. When both this style and a framework template apply, this 中智 color system wins: repaint the template's fills, strokes, labels, backgrounds, and emphasis marks into the palette below.
