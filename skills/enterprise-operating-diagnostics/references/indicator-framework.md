# 指标框架

## 一、经营成效

经营成效关注规模增长与利润增长是否真实、匹配、可持续。分析时应从规模类指标切入，再用效益类和现金类指标校验。

财务指标发现异常后，要继续追问业务驱动因素。涉及采购、生产、销售、研发、供应商、产品全生命周期、经营分析报告闭环的方法，见 `business-analysis-methods.md`。

### 1. 规模类指标

**营业收入**

- 重点看营业收入、营收增速、主业营收占比、销售额。
- 高营收不等于高质量增长。警惕大宗贸易、工程过水、并表拉动、融资需求驱动的规模冲刺。
- 主业营收占比比笼统收入更适合多元化集团；销售额适合预售、平台型或行业地位明显的业务。

**资产规模**

- 资产可包括表内总资产、净资产，也可包括表外管理资产、管理面积、客户数、项目数等行业特定规模。
- 关注资产增长来源：利润留存、股东注资、负债扩张、并购并表、资产评估增值。
- 金融、资管、物业、平台运营等行业可将表外管理规模作为重要补充。

### 2. 效益类指标

**利润总额 / 净利润 / 归母净利润**

- 利润比营收更接近经营质量，但仍可能受资本化、评估增值、资产处置、补贴、非经常性损益影响。
- 国企和集团公司要特别看归母净利润。若优质业务利润被少数股东分走，合并净利润可能好看而归母收益偏弱。

**ROE / 归母ROE**

- 用于判断股东投入回报，适合国资保值增值和股东视角。
- 必须结合净资产质量和利润质量，剔除明显非经常性或不可持续收益后再判断。

**周转率**

- 总资产周转率：对重资产企业有一定价值，但可能被低利润贸易收入冲高。
- 存货周转率：适合制造、零售、快消、批发、医药化工、房地产和土地开发类企业。
- 应收账款周转率：用于识别产业链地位、政府回款压力、信用政策放宽和坏账风险。

**收现比 / 利现比**

- 收现比 = 经营活动现金流入 / 营业收入。
- 利现比 = 经营活动现金流量净额 / 净利润。
- 这两个指标用于约束营收和利润真实性。收现比大于 1 可能来自历史应收回笼或预收款增加；利现比长期偏低说明利润未转化为现金。
- 金融投资类企业需谨慎使用，因为现金流量表分类可能不适配普通工商企业逻辑。

### 3. 经营成效常用分析链

1. 先看 ROE 或净资产收益水平，判断股东回报是否偏弱。
2. 再看营收与利润增速是否匹配，识别规模冲刺或利润异常。
3. 深挖利润构成，剔除公允价值、处置收益、补贴、资本化等不可持续因素。
4. 用收现比、利现比、应收账款、存货验证营收利润质量。
5. 输出现状小结和未来关注，例如核心主业可持续性、应收回款、信用减值、利润侵蚀、主业转型效果。

## 二、经营安全

经营安全关注企业能否可持续经营，尤其关注债务压力、增长结构和现金造血能力。

### 1. 债务水平

**资产负债率**

- 资产负债率是基础指标，但不能单独下结论。
- 警惕时点操纵现金、资产评估增值、交叉持股、并表艺术、推迟转固、少数股东权益过高等导致的表观健康。
- 区分有益负债与压力负债。应付账款、合同负债、保证金等可能体现强势产业链地位；有息负债才是主要偿付压力。

**净负债率**

- 净负债率 = `(有息负债 - 货币资金) / 净资产`。
- 用于衡量有息债务缺口与净资产承受能力。
- 若货币资金受限、短期沉淀异常或少数股东权益占比高，应做调整或提示局限。

**长短债结构**

- 长债占比高通常说明偿债节奏更平滑；短债占比过高意味着短期流动性压力。
- 要结合债务到期分布、债券回售、银行授信续作、非标融资和担保代偿风险。

**融资成本**

- 与 LPR、同评级主体、同地区平台、同业企业比较。
- 若融资成本下行慢于市场利率，可能反映信用资质或再融资压力。

**EBITDA 利息倍数**

- EBITDA 利息倍数用于衡量利润覆盖利息的能力，底线通常为 1 倍。
- 对利润质量较差、补贴依赖重、公允价值收益高的国企和平台公司，应弱化单独使用，转向现金流覆盖。

**资产与负债增速比**

- 若资产增速长期低于负债增速，说明资产做大更多依赖举债，安全性下降。
- 若资产增速高但现金流和利润不改善，要进一步识别资产质量和变现能力。

### 2. 增长结构

**边际效益**

- 观察新增收入带来的新增利润，常用 `利润增量 / 收入增量`。
- 边际效益下降说明扩张质量变弱，可能来自低毛利业务、成本上升、融资费用增加、项目公益性增强或价格竞争。
- 边际效益为负不必直接否定，要结合行业整合、产能爬坡、抢占市场、长尾收益等阶段性逻辑。

**运营杠杆**

- 运营杠杆关注固定成本占比。固定成本越高，利润对收入波动越敏感。
- 对基建、制造、医药研发、互联网平台等固定投入重的企业，要看收入增长能否摊薄固定成本。
- 财务费用虽属财务杠杆，但在高债务平台公司中也会形成类似固定成本压力。

**营收与应收账款增速比较**

- 若应收账款增速显著高于营收增速，警惕提前确认收入、放宽信用政策、政府或客户拖欠。
- 对地方国企需同时看其他应收款、长期应收款、合同资产和政府往来款。

**存货增速**

- 与营收、销售额、流动资产、总资产、项目结转节奏一起分析。
- 存货增速远高于收入增速，可能是销售不畅、项目沉淀、土地或工程资产变现慢。
- 城投和基建公司要区分土地开发成本、市政项目支出、公益性资产和可销售资产。

### 3. 现金流水平

**三张现金流量表**

- 经营性现金流：持续为正通常说明业务造血；长期为负说明经营消耗现金，但需结合成长阶段、备货、政府回款周期判断。
- 投资性现金流：为负可能代表扩张投入；为正可能是投资回报，也可能是变卖资产求生。
- 融资性现金流：为正说明仍能外部输血；为负可能是偿债付息或分红，也可能反映融资渠道收缩。

**资产获现率**

- 资产获现率 = 经营活动现金流量净额 / 总资产或经营性资产。
- 用于观察资产运营是否产生现金净流入。

**财务费用覆盖率 / 经营现金流利息覆盖**

- 常用经营活动现金流量净额或经营现金流入与利息支出、财务费用比较。
- 若经营现金流不能覆盖利息，公司依赖再融资或政府支持维持。

**自由现金流**

- 自由现金流 = 经营活动现金流量净额 - 资本支出。
- 持续为正且趋势改善，说明企业能自我扩张；持续为负说明依赖外部资金。
- 投资密集型行业可容忍阶段性为负，但必须判断融资环境和投资回报能否支撑。

### 4. 经营安全常用分析链

1. 先看债务是否真实安全：表观资产负债率、净负债率、有息债务、长短债、融资成本、担保和隐性债务。
2. 再看增长是否透支：边际效益、运营杠杆、收入与应收/存货/资产增速匹配。
3. 最后看现金能否自养：经营现金流、自由现金流、利息覆盖、投资和融资现金流。
4. 输出综合判断：安全、基本安全但依赖外部支持、短期可维持但中长期承压、或经营安全风险较高。
5. 给出未来关注项：融资环境、债务到期、政府支持、回款、存货去化、投资节奏、核心业务现金创造能力。

## 三、业财融合补充指标

当用户要求“经营分析”而不只是“财务分析”时，按业务场景补充以下指标：

- 采购：采购总成本、材料价格差异、账期资金成本、来料合格率、交付及时率、供应商经营风险。
- 生产：单位材料成本、材料用量差异、人工工时、人效、制造费用率、产能利用率、单位固定成本、质量损失成本。
- 销售：客单价、销量、产品结构、客户结构、销售费用投入产出、促销毛利贡献、信用额度使用率、逾期应收。
- 研发：产品全生命周期综合毛利率、项目阶段成本偏差、BOM 变化影响、研发费用预算执行、研发投入商业化转化。
- 管理闭环：改善措施完成率、收益兑现率、责任部门、里程碑、风险应对状态。
