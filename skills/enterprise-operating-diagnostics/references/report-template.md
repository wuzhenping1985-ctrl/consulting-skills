# 报告模板

## 输出定位

输出应像一篇中文专业分析文章或咨询报告，而不是财务教材。读者通常是企业负责人、国资监管部门、战略规划团队、投融资团队或咨询项目组。

## 基础结构

```markdown
# 标题

## 一、分析背景与核心判断

简述公司类型、业务定位、分析期间、资料来源和总体判断。不要铺垫过长，第一屏就给出明确判断。

## 二、经营成效

### （一）规模增长
判断营收、销售额、资产规模或管理规模是否增长，以及增长来源是否健康。

### （二）效益表现
判断利润、归母净利润、ROE、周转效率是否改善，以及利润是否真实可持续。

### （三）现金约束
用收现比、利现比、经营现金流、应收账款、存货等验证经营成效质量。

### （四）小结
用 2-4 条概括现状和未来关注。

## 三、经营安全

### （一）债务水平
分析资产负债率、净负债率、有息债务、长短债、融资成本、利息覆盖、担保和隐性债务。

### （二）增长结构
分析边际效益、运营杠杆、营收与应收账款增速、存货增速、资产与负债增速。

### （三）现金流水平
分析经营、投资、融资现金流，自由现金流，经营现金流对利息和投资的覆盖。

### （四）小结
判断经营安全等级、关键压力来源和未来关注。

## 四、综合结论与规划启示

将经营成效与经营安全合并判断，转化为十五五规划或战略动作启示。
```

如果用户要求加入业务经营分析，可在经营成效和经营安全之间加入：

```markdown
## 三、业务经营分析

### （一）战略与业务结构
判断当前收入、利润、产品、客户和资源配置是否支撑战略目标。

### （二）采购与供应链
分析采购总成本、供应商风险、材料价格、账期、交付、质量和库存。

### （三）生产与成本
分析材料、人工、制造费用、产能利用率、固定/变动成本、质量损失和固定资产投资效率。

### （四）销售与回款
分析定价、产品结构、销售费用、促销效果、信用政策和应收账款。

### （五）研发与产品生命周期
分析研发投入、项目阶段成本、BOM 变化、产品全生命周期综合毛利率和商业化转化。

### （六）改善措施与风险挑战
提出可落地措施、责任主体、收益预估、执行阻碍和跟踪机制。
```

如果用户只要求经营安全，可直接使用：

```markdown
# 案例之XX公司经营安全分析

## 一、债务水平

## 二、增长结构

## 三、现金流水平

## 四、综合结论
```

## 段落写法

每个分析段落优先使用以下顺序：

1. 判断句：先说明好、坏、矛盾或风险。
2. 数据证据：列出关键年份、指标、增速或占比。
3. 业务解释：解释为什么出现这种表现。
4. 风险或启示：说明这对经营安全、经营成效或规划意味着什么。

业务经营分析段落可使用：`业务场景 -> 关键驱动因素 -> 数据证据 -> 管理问题 -> 改善动作 -> 风险挑战`。

示例句式：

- `从债务维度看，公司表观资产负债率并不算极端，但有息债务和短债压力显示其真实偿债压力并不轻。`
- `营收快速扩张并未同步转化为利润，说明新增业务的边际效益正在下降。`
- `利润改善与经营现金流背离，意味着账面收益尚未形成真实现金回流。`
- `当前经营安全并非取决于账面盈利，而取决于再融资能力、政府支持持续性和存货/应收的变现节奏。`
- `毛利率下滑不能简单归因于市场竞争，还需要拆到产品结构、材料价格、BOM变化、产能利用率和销售折扣。`
- `应收账款上升本质上是信用政策和客户结构的结果，需要同时评估销售增长质量和资金链承受能力。`

## 小结写法

小结不要重复前文数据，直接转为判断：

```markdown
小结来看，公司当前经营安全呈现“短期可维持、长期看造血”的特征。短期内，较强的融资能力和政府支持能够缓冲债务压力；但从中长期看，若经营现金流无法转正、自由现金流缺口持续扩大，公司仍将依赖外部输血维系扩张和偿债。

后续应重点关注三件事：一是债务到期和再融资成本变化；二是应收账款和存货的回收/去化节奏；三是核心主业能否形成稳定经营现金流。
```

## 表格建议

只放能支撑判断的表。常用表包括：

- 主要财务指标趋势表：收入、利润、净资产、总资产、资产负债率、经营现金流。
- 债务结构表：有息债务、短期债务、长期债务、货币资金、净负债率、融资成本。
- 增长质量表：营收增速、利润增速、应收增速、存货增速、边际利润率。
- 现金流表：经营、投资、融资现金流，自由现金流，利息覆盖倍数。
- 业务驱动表：销量、单价、产品结构、单位成本、产能利用率、销售费用、应收周转、库存周转。
- 改善闭环表：问题、原因、措施、责任部门、预期收益、风险挑战、完成时点。

表后必须跟解释，不要让表格替代分析。

## Word 格式建议

- 中文正文使用 `微软雅黑` 或 `宋体`，正文 10.5-12 pt。
- 一级标题使用中文编号：`一、二、三、四、`。
- 二级标题使用：`（一）（二）（三）`。
- 三级标题使用：`1. 2. 3.`。
- 段落保持紧凑，避免过多空行。
- 长数字统一单位，例如 `亿元`、`%`、`倍`。
- 若使用外部资料，在文末加入 `参考资料`，列出报告名、年报名或网址。

## 质量检查

交付前检查：

- 是否有清晰总判断。
- 是否解释了指标背后的业务原因。
- 是否识别了利润与现金流、规模与效益、表观负债与真实债务之间的矛盾。
- 是否将风险转化为未来关注项或规划启示。
- 是否把财务异常追溯到业务场景和管理动作。
- 是否给出可执行的改善措施、风险挑战和跟踪闭环。
- 是否避免未经来源支持的精确数字。
