# 业务经营分析方法

本参考文件抽象自《企业经营分析：揭秘商业本质，提升管理效益》的方法论，并结合本 skill 原有的财务诊断框架使用。使用时只吸收方法，不复制原书表述。

## 一、总原则

经营分析不是财务报表复述，而是为经营决策、价值创造、核心竞争力提升和风险规避服务。每次分析都要回答四个问题：

1. 管理层真正要决策的问题是什么。
2. 财务数据背后的业务场景是什么。
3. 哪些业务驱动因素造成了收入、利润、成本、现金流或风险变化。
4. 可以落地的改善措施、阻碍和跟踪机制是什么。

财务分析与经营分析的区别：

- 财务分析偏结果、报表、事后评价；经营分析偏业务场景、关键要素、建模、决策和改善。
- 财务分析发现异常，经营分析解释异常并推动行动。
- 经营分析要把数字拆到产品、客户、项目、订单、供应商、BOM、工序、人员、产能、费用和流程。

## 二、战略与目标分析

在十五五规划、战略诊断或年度经营分析中，先澄清战略，再判断经营数据是否支持战略。

### 1. 内外部与核心竞争力

- 用 SWOT、行业对标、市场地位、产品竞争力、客户结构、成本能力、研发能力、渠道能力等识别核心竞争力。
- 对多产品企业，不只看收入占比，还要看毛利率、成长性、重要性、资源匹配和未来市场空间。
- 若成本分摊粗放导致产品盈利失真，应先重建成本归集逻辑，再判断重点产品和增长点。

### 2. 财务三角

用 `增长性-盈利性-流动性` 检查战略取舍：

- 追求增长通常会牺牲价格、利润率或现金回款。
- 保持盈利可能需要放弃低毛利订单、低价扩张或过度信用政策。
- 保持流动性可能限制扩张速度、库存备货和客户账期。
- 不同阶段优先级不同：成长期可优先增长，但不能忽视现金；成熟期更应重视盈利和流动性。

### 3. 多目标体系

不要只设一个财务目标。可从市场地位、创新、生产力、实物和财力资源、获利能力、管理者绩效、员工绩效、社会责任等领域选择重点，并转化为可衡量指标。

## 三、采购业务分析

### 1. 从材料价格最低转向采购总成本最低

采购总成本应覆盖全价值链，而不是只比报价。常见要素：

- 显性成本：材料价格、运输、仓储、订单处理、供应链成本、返利或折扣。
- 资金成本：账期长短、预付款、承兑、资金占用成本。
- 质量成本：来料不良、退换货、停线、返工、内部损失、客户索赔。
- 交付成本：交期不稳定、缺货、加急运输、产线等待。

判断供应商时，可用 `采购总成本 / 可比采购数量` 得到可比单价。若质量数据不足，先计算可量化的资金和物流成本，同时把质量风险作为定性约束。

### 2. 采购降本

常见降本路径：

- 集中采购：提升规模议价能力，但要防止单一供应商依赖。
- 需求标准化：减少物料种类，提高批量，降低库存和采购复杂度。
- 国产替代或技术替代：降低单价，但必须验证质量、交付和全生命周期成本。
- 长协、套保或价格联动：应对大宗原材料波动。
- 激励机制：把采购降本与质量、交期、资金占用一起考核，避免只压价格。

### 3. 自制或外购

先看战略、质量、交付、内部产能、供应商关系，再比较经济成本。

相关成本判断：

- 有剩余产能且不能生产其他产品：自制主要看变动成本。
- 有剩余产能且可生产其他产品：自制要加入机会成本。
- 无剩余产能：自制要加入新增固定资产、人员、维护等全成本。
- 外购要加入采购价、运费、订单处理、管理成本、缺货成本、质量成本和供应不稳定风险。

最终结论不要只写“自制更便宜”或“外购更便宜”，要说明战略控制、质量交付、产能利用和供应链韧性。

### 4. 库存与供应商风险

- 库存周转率不是越高越好，要结合行业、业务模式、客户响应要求、价格趋势、供应风险和安全库存。
- 安全库存要验证是否真的“安全”：是否过高占用现金、是否掩盖预测不准、是否导致呆滞物资。
- 供应商管理不应只看供货评分，还要看供应商经营风险、财务状况、产能、质量体系、核心客户依赖、现金流压力。
- 对核心供应商，建议由采购、财务、质量、研发或内审联合走访，形成风险评估和帮扶措施。

## 四、生产业务分析

### 1. 成本分析要深入现场

生产分析要从财务数据走向工厂现场、工艺流程和管理动作。优先找影响大的成本项和异常波动项，不做均匀用力的泛泛分析。

### 2. 材料成本

直接材料差异可拆为：

- 价格差异：采购价格、替代材料、供应商变化、汇率、大宗商品价格。
- 用量差异：BOM、损耗率、良品率、工艺变更、设计变更。
- 结构差异：产品组合变化导致材料成本率变化。

关注仓库盘点、呆滞物资、积压物资和 BOM 准确性。BOM 是连接研发、采购、生产和成本分析的基础数据，BOM 不准会导致报价、成本、库存和毛利判断全部失真。

### 3. 人工与制造费用

- 人工分析要结合计件/计时制度、工时记录、产量、人员结构、加班、外包、学习曲线和人效。
- 制造费用要拆到能源、折旧、维修、辅料、间接人工、设备利用率和作业动因。
- 对重资产企业，重点看产能利用率、固定成本摊薄、设备效率和单位制造费用。

### 4. 固定成本、变动成本与本量利

用固定成本和变动成本解释利润弹性：

- 高固定成本企业在销量上升时利润弹性强，但销量下滑时风险也大。
- 本量利分析可用于测算保本点、安全边际、价格降幅承受能力、销量目标和产品组合影响。
- 不要机械套公式，必须结合产能约束、价格策略、产品结构和市场需求。

### 5. 质量成本

质量成本可拆为预防成本、鉴定成本、内部损失成本、外部损失成本。质量问题会转化为返工、报废、停线、客户索赔、召回、品牌损害和交付风险。经营分析要判断企业是在“前端预防”还是“后端补救”。

### 6. 固定资产投资

固定资产投资不能只看短期报表指标，要按全生命周期测算：

- 初始投资、使用年限、产能、运行成本、维护成本、残值。
- 预计销量、价格、毛利、现金流、税费、营运资金占用。
- 投资回收期、净现值、内含报酬率和敏感性分析。
- 投后跟踪：实际产量、利用率、单位成本、现金流与立项预测是否一致。

## 五、销售业务分析

### 1. 定价

成本加成定价适合成本较稳定、议价空间有限或管理简单的场景，但可能忽视市场接受度和竞争价格。

目标成本法适合竞争激烈或客户价格刚性的场景：先确定市场可接受价格和目标利润，再倒推目标成本，形成采购、研发、生产、销售协同降本压力。

### 2. 应收账款与信用政策

应收账款不仅是财务科目，也是销售策略和客户质量的结果。

分析信用政策时关注：

- 客户分层、信用额度、信用期限、逾期规则和审批权限。
- 销售增长是否依赖放宽账期。
- 应收账款、合同资产、其他应收款和坏账准备是否与收入增长匹配。
- 回款预测是否进入资金计划，最差情景下资金链是否承受得住。

### 3. 销售费用与促销

销售费用要看投入产出，而不是简单压降。常见拆解：

- 渠道费用、促销费用、差旅拜访、会议推广、物流配送、售后服务、经销商返利。
- 按客户、产品、区域、渠道、项目统计费用和毛利贡献。
- 促销分析要比较促销前后销量、毛利、库存去化、客户留存、价格体系破坏和费用回收期。

## 六、产品研发分析

### 1. 产品全生命周期综合毛利率

对长生命周期产品，不要只看首年毛利率。应估算整个生命周期的销售收入、销售成本、价格年降、材料年降、人工上涨、产量变化和退出期成本。

可用：

`全生命周期综合毛利率 = (生命周期销售总收入 - 生命周期销售总成本) / 生命周期销售总收入`

也可按各年度毛利率和产量权重计算加权平均毛利率。

### 2. 项目阶段管控

按立项、研发、试制、量产等阶段设置毛利率或成本目标。每个阶段结束后比较目标与最新预测，追踪差异来源：

- 原材料价格变化。
- 客户图纸或需求变更。
- BOM 更新。
- 结构设计优化或增本。
- 产量预测变化。

若客户变更导致增本，要及时保留证据并推动销售谈判；若内部设计导致成本偏高，要组织降本评审。

### 3. 研发费用

研发费用分析不要只问“花了多少”，要看研发阶段、项目组合、资本化/费用化、预算执行、里程碑、产品成功率、技术复用和未来商业化收益。研发分析应帮助判断投入是否形成核心竞争力。

## 七、经营分析报告与闭环

### 1. 四步法

经营分析报告按以下四步组织：

1. 聚焦主题：从管理层痛点、重要性、紧急性和影响金额中选一个主问题。
2. 调研分析：提出问题、收集证据、评估证据、得出结论并验证。
3. 改善措施：提出可执行措施，明确责任部门、动作、收益、成本和实施难度。
4. 风险挑战：说明执行阻碍、应对方案、收益预期和跟踪机制。

### 2. 选题原则

- 在被动要求与主动洞察之间平衡。
- 在外部因素与内部因素之间平衡。
- 在自上而下的战略视角与自下而上的一线问题之间平衡。
- 重大因素突变时及时调整主题。
- 敏感议题要提前与管理层确认时机。

### 3. 报告表达

报告目标不是展示工作量，而是帮助业务和管理者快速理解、激发讨论、找到改善机会。

推荐结构：`核心结论 -> 关键证据 -> 原因拆解 -> 改善措施 -> 风险挑战 -> 跟踪机制`。

用业务语言解释财务结论。少用纯财务术语，必要时加解释。图表要服务判断，不能堆砌。

### 4. 经营分析会与闭环

会前：完成初步分析、调研访谈、关键人员沟通、报告预演和可能质疑准备。

会中：推动讨论和决策，不只宣读报告；关注事实，也关注人的立场、压力和协同。

会后：建立改善措施台账，跟踪责任人、完成时间、关键里程碑、收益兑现、风险变化和经验复盘。
