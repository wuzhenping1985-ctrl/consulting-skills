# Management Consulting Methods

## Core Workflow

1. Reframe the user's request into a decision, problem, or deliverable.
2. Define the governing question and success criteria.
3. Build a MECE issue tree or logic tree.
4. Form hypotheses that can be tested with data, interviews, benchmarks, or workshops.
5. Translate the issue tree into workstreams, analyses, data needs, interview questions, and deliverables.
6. Synthesize into answer-first communication: finding, evidence, implication, recommendation.

## Method Selection

- Use issue trees for problem structuring and work planning.
- Use hypothesis-driven planning when time is limited and ambiguity is high.
- Use root-cause analysis when symptoms are clear but causes are not.
- Use stakeholder mapping when organizational alignment or adoption risk matters.
- Use operating model logic when strategy must become roles, processes, governance, systems, and KPIs.
- Use change management logic when behavior, incentives, or capability adoption matters.

## Guardrails

- Do not force MECE where the problem is exploratory; use iterative hypotheses instead.
- Do not confuse framework labels with insight.
- Do not skip stakeholder, governance, and change risks when recommendations require implementation.
- Prefer a simple structure that creates action over a complex structure that only categorizes.
