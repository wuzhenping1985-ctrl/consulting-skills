# 可编辑重画样页

按顺序重画D004、D006、E006、E011。`可编辑复刻样页.pptx`为已核验的成品，`renders/`为成品重新导入后的渲染图；原页在上一级`previews/`中。

文字、图形和连线均为原生可编辑对象，未嵌入原页截图。完整原文、分组与顺序已逐项比对；字体换行和少量曲线细节仍可能与原页不同。E006标题的五大保障与图中的四项不一致，忠实复刻保留此原文问题，迁移设计时不得沿用。

## 代码及复用

- `draw.mjs`提供基本形状、路径、文字、箭头和分段线。
- `pages/d-pages.mjs`、`pages/e-pages.mjs`分别绘制两组参考；E文字通过`E/`中记录读取。
- `build.mjs`组合四页并输出PPTX与预览。运行前用`load_workspace_dependencies`确认Node与`@oai/artifact-tool`路径，在本目录的`node_modules`中解析该包，或在带依赖的工作目录复制这些文件。以Node运行`build.mjs <工作目录>`，不要覆盖参考成品。重新交付PPTX时执行presentations的最终校验。

固定坐标只用于重画这四页。制作新内容时先确认原文各层的数量和关系，再修改区域比例、文字宽高与图形数量；完整说明须在本页读懂。
