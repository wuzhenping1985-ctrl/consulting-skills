# E：科技企业十五五科技创新战略规划——逐页设计研究

## 一、观察依据与全稿设计方法

已实际查看中文修复后的E001—E014全部14张页面，同时核对`inventory.json`及E006、E011文字坐标。原件为16∶9画幅，对应1280×720设计坐标。图片预览为1440×810，测量时应按8/9换算。源文件保持只读。

这份参考稿依靠连续的信息图来组织正文。多数内容页以顶部约20%—25%的高度承载页标题和总述，下方约65%的高度承载图解；导航固定在右上角，正文分组和图形比例则随内容变化。第6页省去常见的总述段，直接给体系图较大面积；第11页采用开放的四块正文与贯通箭轴；第13页用框架图、对应关系、评级表和矩阵共同解释一个案例。

主要层级是深灰粗体页标题、深灰粗体总述、蓝色分组标题、深灰正文及段内蓝色重点。源第6页的标题为22pt，分组标题与结构标签多为14pt，正文多为12pt；第11页标题22pt，分组标题16pt，正文14pt。重绘需要换算为画布像素并核验视觉字号，不能直接把pt数值当作px使用。颜色以主蓝、辅助蓝、浅蓝、白和深灰为主，橙色集中于少量提示及页脚标记。

图形可以占用较大面积，前提是承担清楚的信息关系。屋顶统领目标，包围边界区分1与3，矩阵表示分类，泳道区分周期，箭轴统一方向。参考中的浅色底板、虚线和色带有时正是分组依据，不能按统一的去装饰规则全部删除，也不能只保留正文再随意补一个圆环。

## 四、严格对照复刻的验收标准

**整页构图。** 将参考与复刻缩至相同宽度并排看，标题区、主体区、辅助区、重色面、留白和主图轮廓应具有相同的主次关系。E6若变成四栏正文，E11若变成四张卡片，即使文字齐全也不通过。建议以1280×720坐标比较关键锚点，屋顶峰、各层边界、中轴、靶心等偏差超过8px时重新核对；主要区块宽高差超过5%时说明原因并修正。容差用于定位问题，不能替代逐页判断。

**信息图解。** 每个包围区、分割线、箭头、节点和色带都需对应参考中的语义。E6验收5原则、1条主线、3抓手、4个实际保障，尤其检查两层分组；E11验收4个并列保障和一个共同方向，靶上的环不能被解释为4项保障的比例。E7需保留5项观察、3类决策及其内部筛选关系。

**文字与图形比例。** 对照标题基线、段落起点、每段行数、字号层级与蓝色重点范围。不能通过缩小全部文字来迁就错误的图区比例，也不能把原段落改成若干短标签。细线、虚线和底色应与参考具有相近的视觉重量；不以边框数量、形状数量或图形复杂程度代替设计质量。

**真实可编辑。** 文字、屋顶、层次底板、箭轴、靶体、线条和必要节点应可分别修改；不得把原页整图、截图或不可拆分的整页矢量图当作复刻。允许按语义分组，但分组不能改变文本项数和关系。

**缺陷与复用边界。** 缺字、单字落行、标题被连线穿过等应记录原因，不照搬为设计规则。E6的五大/4项不一致在本轮忠实复刻中保留并标记，后续应用须以新内容为准。无溢出、文字完整、文件能打开只是基础检查；整页构图和信息图解均通过，才可确认掌握该页设计。

## 五、本轮重绘验收

已编写`recreations/e-pages.mjs`，导出`buildEPages(deck)`，原生重画E6、E11。图形及文字均重新构建，文字内容读取逐页转录，未复制原幻灯片或导入页面截图。代码通过语法检查；在统一构建的`candidate.pptx`中核对XML文本，E6的30个来源文本块、E11的14个来源文本块均完整覆盖。该核对忽略空白和换行，不忽略实词、数字和标点。

已将第三版渲染`recreations/renders/slide-3.png`、`slide-4.png`与中文正常的原页逐页对照，结论如下。

- **E6：** 屋顶与三层横向结构、5项原则、1条主线与3个抓手的包围关系、4项实际保障均与参考一致；任务正文保留3/3/3/4项，文字完整并位于底板内，项目符号与首行对齐。标题断行、字号和起点已对照修正。
- **E11：** 4块开放正文、上下错位的分界、共同箭轴和右侧椭圆靶保持原构图；4类保障各2项措施完整，短期与中长期的内部区分保留。段内蓝色强调恢复，行距接近参考，标题垂直位置已修正。

残余差异主要为原字体与本地Microsoft YaHei UI之间的字面宽度、少量正文换行位置及小靶图标的局部曲线。它们未改变整页分区、信息层级、措施归属或阅读方向。本轮已通过整页构图、内容图解、正文完整及原生可编辑检查，未进行逐像素一致性认证。源稿五大保障与4项图示的矛盾仍作为原稿问题单独记录，后续应用不沿用。
