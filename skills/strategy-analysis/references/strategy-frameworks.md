# Strategy Frameworks

## Use 3C When

Use company/customer/competitor logic to structure broad strategic diagnosis.

- Customer: needs, segments, buying criteria, pain points, willingness to pay.
- Competitor: position, capabilities, cost, channels, differentiation, likely moves.
- Company: assets, capabilities, economics, constraints, ambition.

## Use Five Forces When

Use for industry attractiveness and profit pressure:

- Rivalry
- Buyer power
- Supplier power
- Threat of substitutes
- Threat of new entrants

Avoid using Five Forces as a generic checklist. Translate each force into margin, growth, or risk implications.

## Use Value Chain When

Use to locate control points, profit pools, bottlenecks, and capability gaps.

## Use Portfolio Logic When

Use for multi-business or multi-product resource allocation:

- Market attractiveness
- Competitive position
- Financial contribution
- Strategic fit
- Capability leverage
- Risk and optionality

## Use Scenario Planning When

Use when uncertainty is material and not reducible by quick research:

- Policy/regulatory direction
- Technology route
- Demand adoption speed
- Capital cycle
- Competitive entry

Name the uncertainty, define 2-4 plausible states, and identify no-regret moves.
