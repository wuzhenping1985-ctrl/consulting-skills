# CIIC/Yuexiu PPT Style Guide

Use this reference when a PDF-to-PPT conversion must match the Yuexiu/CIIC consulting proposal style.

## Extracted Template Baseline

- Slide size: 33.87 cm x 19.05 cm, widescreen 16:9.
- Theme colors:
  - Dark text: `#383838`
  - White: `#FFFFFF`
  - Orange accent/page marker: `#FF4200`
  - Primary blue: `#1C55FE`
  - Secondary blue: `#547FFE`
  - Light blues: `#8DAAFE`, `#B3D4FE`, `#CFDBFF`
  - Rule/link blue: `#126BF7` / `#0042FF`
  - Neutrals: `#E7E6E6`, `#DCDCDC`
- Normal Chinese font: Microsoft YaHei / 微软雅黑.
- English catalog labels such as `CONTENTS`: Arial is acceptable when inherited from the template.
- Display numeral font: Impact for large standalone KPI numbers and percentages only.

## Layout Roles

- `封面`: formal cover.
- `目录`: agenda/catalog.
- `章节`: chapter divider.
- `内页版式-基础`: standard content page with one key-point lead.
- `1_内页版式-基础`: standard content page without key-point lead.
- `内页版式-左右等分`: two equal columns.
- `内页版式-左右1:2`: narrow left column, wide right column.
- `内页版式-左右2:1`: wide left column, narrow right column.
- `内页版式-左中右三分`: three equal or near-equal columns.
- `内页布局-右侧强调`: right blue emphasis rail.
- `1_内页布局-右侧强调`: right emphasis rail plus left main content lead.
- `内页布局-左侧强调`: left blue emphasis rail plus right content columns.
- `封底`: back cover.

If the bundled template does not expose a specialized layout, recreate the same structure with native shapes using the standard content layout, while preserving title position, blue rules, footer, page marker, and column proportions.

## Typography

- Cover title: about 34pt, bold, Microsoft YaHei, dark text, cover title placeholder.
- Cover subtitle/tagline: about 24pt; speaker/date line about 12pt.
- Cover composition must remain formal and sparse. Use only the report title, subtitle/topic/client/project, date/team/source line, and template-provided brand/background elements. Do not add analytical conclusion banners, "core thesis" labels, KPI cards, diagnostic boxes, charts, evidence tables, or model-framework diagrams to the cover unless the user explicitly asks for an analytical cover.
- Catalog title: template `目录` placeholder; do not redraw it as a generic text box.
- Section divider title: 24pt bold; optional chapter description 16pt.
- Content-page title: 24pt bold Microsoft YaHei, dark text. Use 22pt or 20pt only for long titles that do not fit. Avoid 18pt titles except for extreme cases.
- Key-point lead text: 16pt Microsoft YaHei.
- Main body: 14pt Microsoft YaHei.
- Dense table/support text: 12pt preferred; 10-11pt only when content cannot fit after reflow.
- Footers/page numbers: preserve template sizing and placement. The base template already provides the right-bottom page number/page marker, so do not manually draw another page number or orange marker on body slides.
- Large KPI numerals: Impact, usually 20-24pt or larger depending on the visual hierarchy; use Microsoft YaHei for units and Chinese labels.

## Page Geometry

- Master title area: `x=1.83 cm`, `y=0.00 cm`, `w=30.16 cm`, `h=2.86 cm`.
- Standard upper blue rule: `x=1.86 cm`, `y=3.14 cm`, `w=30.14 cm`, color `#0042FF`.
- Standard lower blue rule: `x=1.86 cm`, `y=17.95 cm`, `w=30.14 cm`, color `#0042FF`.
- Standard key-point lead row: starts near `x=1.83 cm`, `y=3.52 cm`, height about `1.01 cm`.
- Footer URL: near `x=29.43 cm`, `y=17.97 cm`, `w=3.53 cm`, `h=0.60 cm`.
- Orange page marker: near `x=31.10 cm`, `y=17.29 cm`, `w=0.67 cm`, `h=0.67 cm`.
- Main content must stay below the key-point lead/upper rule and above the lower rule/footer. Do not cover either rule.

## Column Proportions

- Two equal columns: left `x=1.83 cm`, `w=14.84 cm`; right `x=17.16 cm`, `w=14.84 cm`.
- Left 1 / right 2: left `x=1.83 cm`, `w=9.34 cm`; right `x=13.63 cm`, `w=18.37 cm`.
- Left 2 / right 1: left `x=1.83 cm`, `w=18.37 cm`; right `x=22.66 cm`, `w=9.34 cm`.
- Three columns: approximately `x=1.83 cm`, `12.38 cm`, `22.93 cm`; widths about `9.07 cm`.
- Right emphasis rail: blue rail begins near `x=23.20 cm`, `w=10.67 cm`; left main content should end before `x=21.86 cm`.
- Left emphasis rail: blue rail occupies `x=0.00 cm`, `w=11.09 cm`; right content starts near `x=12.01 cm`.

## Style Application

- Use blue fills and lines for structure, hierarchy, emphasis blocks, and side rails.
- Use orange only as a small accent. Do not turn a whole slide orange.
- Keep shapes mostly straight-corner unless the PDF source or template explicitly uses rounded corners.
- Use light blue fills for secondary panels, table headers, tags, and comparison blocks.
- Use white or very light neutral backgrounds for dense content.
- Keep diagrams editable, aligned, and balanced inside the rule-bounded content area.
