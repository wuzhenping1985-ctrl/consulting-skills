# Model Selection Guide

Use this guide to choose a model from `assets/model-library` when turning a PDF or Word report into a consulting PPT.

## General Rules

- Use model decks as editable structure references, not as content sources.
- Prefer a suitable model-library page for each正文/content slide when the report logic reasonably matches one. Use a plain base-template content page only when no model-library structure fits.
- Skip instruction pages, copyright notices, QR-code pages, font-installation notes, color-change tutorials, and catalog pages unless the user asks for template documentation.
- Replace every sample label with report-specific language.
- Prefer a simple, faithful model over a visually complex model that distorts the report logic.
- If a copied model slide contains logos, watermarks, or source-template decorative text, remove them.
- Use the slide content area actively. If a selected model leaves too much unused space after replacing text, scale the diagram/table group up, switch to a richer model, or combine related evidence while preserving readability.

## Selection Heuristics

### Roof / Strategy House

Use `roof-blue.pptx` when the report describes:

- Strategic objectives supported by several pillars.
- A top-level target state with capability, organization, process, talent, digital, or governance supports.
- A management system with roof, columns, base, and foundation layers.
- Transformation architecture or target operating model.

Common slide messages:

- "以战略目标为牵引，构建由X大支柱支撑的管理体系"
- "围绕高质量发展目标，形成目标、能力、机制、保障四层架构"

### Multi-Layer Platform

Use `platform-blue.pptx` when the report describes:

- Layered digital platforms, business platforms, HR platforms, operating systems, governance systems.
- Top-to-bottom relationships such as strategy layer, business layer, capability layer, data layer, technology layer,保障层.
- A foundation/platform that supports upper applications.

Common slide messages:

- "构建分层协同的平台能力体系，支撑业务管理闭环"
- "以底座能力支撑前台应用、管理机制和决策分析"

### Center-Radial

Use `radial-blue.pptx` when the report describes:

- A central concept surrounded by multiple dimensions, stakeholders, initiatives, or capabilities.
- Customer/employee/organization/data centered models.
- Ecosystem coordination around a core platform or management objective.

Common slide messages:

- "以X为中心，联动Y项关键能力形成协同体系"
- "围绕核心目标，构建多主体、多机制联动格局"

### Cycle / Closed Loop

Use `cycle-blue.pptx` when the report describes:

- Plan-do-check-act, annual management cycle, performance cycle, budget cycle, risk control loop.
- Feedback, monitoring, evaluation, improvement, iteration.
- Continuous improvement or operating management closed loop.

Common slide messages:

- "形成目标制定、过程跟踪、评价反馈、改进提升的管理闭环"
- "通过循环迭代机制推动管理效能持续提升"

### Business Process

Use `business-process-blue.pptx` when the report describes:

- End-to-end workflows, implementation paths, customer journeys, procurement/production/sales/R&D processes.
- Cross-department collaboration, handoffs, stage gates, approvals.
- Consulting project workplans with diagnosis, design, implementation, and follow-up.

Common slide messages:

- "按端到端流程重构关键管理动作，明确阶段任务与责任边界"
- "以流程拉通组织协同，提升业务响应和管控效率"

### Timeline / Roadmap

Use `timeline-blue.pptx` when the report describes:

- Phased implementation plans, milestone schedules, annual/quarterly roadmaps.
- "近期-中期-远期" evolution paths.
- Project workplan, transformation roadmap, policy rollout plan.

Common slide messages:

- "按照三阶段推进路径，逐步完成体系设计、试点验证和全面推广"
- "以关键里程碑牵引项目落地，确保方案从设计走向执行"

## Fallback Patterns

- Use `page-design-collection-20160624.pptx` when the report content needs a generic consulting page layout rather than a named business framework. Good candidates include relationship diagrams, two-item comparisons, multiple-option comparison pages, grouped explanation pages, and pages where the main design challenge is visual composition.
- When using `page-design-collection-20160624.pptx`, treat it as a structural reference only. Rebuild or restyle the selected page in the CIIC/Yuexiu base template, replace all placeholder text, remove legacy decorations that conflict with the blue corporate style, and keep the template-provided footer/page marker only.
- Use tables for dense evidence, benchmarks, issue lists, and responsibility matrices.
- Use KPI cards for summary numbers or operating indicators.
- Use matrix pages for comparisons, prioritization, maturity diagnosis, and problem classification.
- Use section divider pages to keep long reports navigable.
- Use appendix slides for detailed tables that are important but too dense for body slides.

## Density And Whitespace

-正文/content slides should feel complete and intentionally composed, not like a small object floating in a large blank canvas.
- Keep readable margins around the title, rules, footer, and page marker, but use most of the available body area for the main diagram, table, or grouped content.
- If a slide has only 1-2 short points, use a comparison/card/KPI/relationship model or combine it with adjacent source content rather than leaving a mostly blank page.
- If a slide is dense, split it into multiple slides instead of shrinking text below the style minimum.
