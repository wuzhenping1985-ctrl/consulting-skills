# 中智蓝色咨询视觉规范

新建、改版与视觉审查同时执行[PPT艺术构图与展示要求](/Users/shampwu/.codex/skills/ppt-art-direction.md)。以整页轮廓、视觉焦点、曲线、几何组合、排字和留白形成艺术感，完整原句就近呈现；未明确要求表格时不采用共同列、固定横行或均匀网格。

本规范用于中智色系的咨询PPT和文章框架图。始终执行 [PPT文字与原文结构要求](/Users/shampwu/.codex/skills/ppt-content-rules.md)。文字和原文结构确定后，再选择视觉表达；不得为适配图形增减原文分点或删去必要说明。

## 一、先看参考，再选择构图

制作前必须阅读 [共享版式库说明](/Users/shampwu/.codex/skills/ppt-layout-library/README.md)，按其中的方法检索 [catalog.json](/Users/shampwu/.codex/skills/ppt-layout-library/catalog.json)，并实际查看 [previews](/Users/shampwu/.codex/skills/ppt-layout-library/previews/) 中对应的预览图。该库从五份、共822页的源文件中整理参考，条目及适用关系以实际目录为准。

先判断原文表达并列、比较、层级、顺序、循环还是其他关系，再选择参考。记录借鉴的页面及具体做法，例如几何组合、主次比例、线条处理、正文位置或留白安排。不要只读条目名称便套用，也不要把参考图中的栏目数变成当前内容的分点数。没有匹配条目时，依据原文关系自行设计。

共享库用于借鉴构图和图形做法。沿用中智色系，按当前来源重建适合的结构；原模板中的文字、数据、标志、二维码、网站和页脚不自动进入成品。用户明确要求原样匹配模板时，保留其指定的母版和重复元素。

本技能中实际可用的品牌资产为 [配色参考图](../assets/contact-sheet.png) 和 [原模板PPTX](../assets/ciic-consulting-2024-template-16x9.pptx)。复制原母版只用于用户明确提出的模板复现任务。

## 二、保持品牌色，灵活安排填充

色值与角色以[mck-ppt-design 配色配置](/Users/shampwu/.codex/skills/mck-ppt-design/references/team/ciic-palette.json)为准，主蓝与图表辅助蓝分别使用。

| 作用 | 色值 | 使用方式 |
| --- | --- | --- |
| 主色 | `#0042FF` | 主要结构、关键节点、标题强调或局部色面 |
| 辅助蓝 | `#1C55FE`、`#547FFE`、`#8DAAFE`、`#C6D4FE`、`#B3D4FE` | 区分原文已有层级、结构区域或次要强调 |
| 背景与辅助底色 | `#FFFFFF`、`#E6E6E6`、`#E2E9FE` | 白底、浅底及必要的分区 |
| 正文 | `#383838` | 浅底上的正文与说明 |
| 少量强调 | `#FF4200` | 关键标记、局部线条或需要注意的内容 |

品牌蓝可以通过文字、线条、轮廓和局部填充出现，不要求每一项都放进浅蓝底色块。内容页允许适度的主蓝色面；主蓝底配白字，浅蓝或浅灰底配深灰字，保持对比清楚。不使用阴影；避免大面积橙红、无关多色及与参考无关的渐变。来源图片、标志或数据图确需保留的颜色按任务要求处理。

统一使用微软雅黑（Microsoft YaHei），渲染前确认该字体可用。用字号、字重、行距和位置区分层级；字体应在实际阅读尺寸下清楚，不能靠持续缩小正文解决拥挤。

## 三、让几何结构表达原文关系

原生可编辑的圆形、圆环、圆弧、扇区、三角形、梯形、多边形、折线、斜线和自由形状均可使用。选择依据是原文含义、参考构图和文字容纳条件，不要求每页换一种图形。

| 原文关系 | 可考虑的视觉做法 | 必须核对的含义 |
| --- | --- | --- |
| 并列或比较 | 开放分栏、对位排版、共享轴线、成组节点 | 保持平行地位和原顺序，不补出因果箭头 |
| 层级或支撑 | 嵌套、平台、屋顶与支柱、主干与分支 | 上下位置必须对应原有父子或支撑关系 |
| 明确的先后过程 | 路径、阶梯、折线、箭头或时间轴 | 保留实际步骤及先后，不把静态分类改成流程 |
| 循环或反馈 | 环路、回流曲线、弧形连接 | 原文必须存在返回、重复或反馈关系 |
| 汇聚或分散 | 向心、发散、汇流或分叉结构 | 中心节点、方向和汇聚结果必须有原文依据 |
| 数量或比例 | 数据图、标尺或有明确口径的面积编码 | 大小、角度、长度与数据对应，不凭视觉效果编造权重 |

线条可以使用直线、折线、斜线或曲线。起止位置和方向须清楚，避免穿过正文及无意义交叉。没有关系需要连接时，可以依靠共同父级、位置和间距表达归属。

用于构图的圆环、扇区或不同大小的区域，不得使读者误认为它们代表未经来源支持的比例、重要程度或成熟度。形状尺寸为容纳文字而变化时，尤其要检查是否产生了这种暗示。禁止为增加艺术感新增层级、闭环、阶段或逻辑中心。

## 四、正文与留白共同组织阅读

完整说明优先直接排在无边框、无底色的正文区，用位置、间距、对齐和必要的细线组织。图形可以承载结构名称、对象及关系，完整正文与对应节点就近或对位安排。只有确实需要表达分组、边界或重点时，才增加容器；不要让每段文字都带一块矩形底板。

页面标题清楚表达本页主题或有依据的判断，保留原文已有标题；不重复增加同义的标题摘要。原文已有总结、证据和限定条件，可以安排在合适位置并保持所属关系，不固定放在顶部或底部，不添加凑版面的口号。

留白可以用于突出主体、分隔信息、平衡构图、容纳图形形态和形成阅读节奏。页面密度随完整内容确定，不设占用率或文字单元数量要求。正文较多时采用清楚的开放排版；框架较简洁时允许更舒展的空间。两者均不得以删除原文内容换取视觉效果。

页面放不下时，先去除无关装饰、调整正文区域、几何比例及布局；仍不足时按任务要求在同一条目下续页，保留标题、编号和归属。必要解释不能移到备注中代替正文。

## 五、使用有含义的图标和版式变化

功能图标可以识别原文中的角色、业务对象、阶段或状态。需要逐项对应时，可以使用风格一致的一组图标，数量随原文对象确定；文字名称和必要解释仍须保留。禁止以相同的装饰图标重复填充每个条目，也不把图标数量当作设计质量。

编号节点、角色标识、原生几何框架和有含义的分组容器可以正常使用。具有按钮、导航或可点击暗示的元素，应有任务或参考版式依据。照片和具象插画用于确实需要的内容，不强制增加装饰图片。

跨页变化应随内容关系和阅读需要产生，可以变化主体位置、正文比例、开放分组、线条和几何组合。相同语义可以复用相同结构；语义不同的页面应重新判断构图。不得为避免重复而强行轮换圆环、三角形、屋顶、流程等图形，也不要求各份参考分别使用若干次。

## 六、分别审查内容与视觉

1. 对照来源，逐层核对项数、顺序、父子关系、编号、名词、数据及限定条件，确认图形没有引入未经支持的含义。
2. 脱离来源和备注，独立阅读渲染页面。读者应能理解每项完整意思、说明与图形的对应关系及阅读顺序；文字压缩成难懂短语时必须返修。
3. 检查视觉作用：所选参考是否实际查看，形状、连线、图标、填充与留白是否有明确用途；反复使用同类矩形容器是否符合内容需要。清楚的并列表达无需添加复杂几何或连接线。
4. 检查实际显示：文字清楚，配色正确，元素对齐，无溢出、遮挡、乱码或误导性比例。确认文件可正常打开，用户要求可编辑的对象保持可编辑。

结构、文字与视觉问题分别记录并修正。渲染成功、形状丰富或色彩统一，均不能抵消原文结构变化和表达不完整的问题。
