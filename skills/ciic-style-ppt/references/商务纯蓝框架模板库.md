# 商务纯蓝框架模板库

Use this reference when a Chinese consulting/report deck needs framework-style visual exposition and the user mentions framework templates, 屋顶图, 多层平台, 中心发散, 循环逻辑, 业务流程, 时间轴流程, or asks to use the attached business-blue templates.

These templates are **structure references**, not content sources or color sources. Use them to choose a visual grammar and prompt image generation; do not copy template placeholder text, QR codes, logos, instructions pages, footers, copyright pages, or original template color styling. Keep generated slide content grounded in the user's report and recolor the structure to the confirmed deck style.

## Selection Rules

- Use 屋顶图 when the source text says several mechanisms support a higher-level goal, conclusion, requirement, or output. Map roof = objective/judgement, pillars = key mechanisms, foundation =制度/数据/组织基础, wings = external conditions or support.
- Use 多层平台 when the source has stacked levels such as 政策层 -> 制度层 -> 执行层, 国资 -> 集团 -> 企业, 战略 -> 机制 -> 行动, or 基础能力 -> 管理机制 -> 目标成果.
- Use 中心发散 when the source has a named central concept and surrounding dimensions. Map center = core issue/goal, outer nodes = source-stated dimensions. Do not use it for unrelated bullet lists.
- Use 循环逻辑 when the source describes recurring management activities or feedback, such as 预算编制 -> 核定 -> 执行 -> 清算 -> 优化. Do not use it for one-time linear tasks.
- Use 业务流程 when the source describes operational steps, decision flow, approvals, role handoffs, or a work mechanism from input to output.
- Use 时间轴流程 when the source is explicitly chronological or implementation-stage based. Use it for reform roadmaps and historical/policy evolution, not for static categories.
- Use 页面整理库 only as a fallback for special layout ideas. Its color and illustration style differ from the business-blue framework set, so adapt only the structure and keep the current deck style fixed.

## Color Re-Mapping Rule

When a slide uses any template in this library, the confirmed deck style controls the colors. By default, repaint the template structure into `中智蓝色咨询模板风`:

- Primary structure: `#1C55FE` CIIC/中智 vivid blue, with `#547FFE`, `#8DAAFE`, and `#CFDBFF` for hierarchy.
- Background and panels: `#FFFFFF` or `#F5F8FF`, with light gray `#E7E6E6` only for subtle dividers.
- Text: `#383838` charcoal on light surfaces and white only on saturated blue blocks.
- Accent: `#FF4200` orange-red only for small emphasis marks, short rules, labels, or dots.

Use the source template's colors only to infer role contrast such as primary / secondary / supporting / disabled; do not reuse its exact colors, gradients, large accent blocks, decorative multicolor treatment, or non-中智 color balance. If the user explicitly confirms a different deck style, recolor to that confirmed style instead of the template's original palette.

## Prompting Requirements

When a slide uses this template library, include in the slide prompt:

- `template_reference_module`: one of 屋顶图 / 多层平台 / 中心发散 / 循环逻辑 / 业务流程 / 时间轴流程 / 页面整理库.
- `template_reference_asset`: the relevant preview contact sheet path, or specific preview slide path if inspected.
- `structure_mapping`: how the report's source points map to roof, platform layers, center/outer nodes, loop nodes, process steps, or timeline stages.
- `style_scope`: use the template as framework grammar only; do not copy placeholder content, page numbers, logo marks, QR codes, instruction pages, non-source claims, or original template color styling.
- `color_mapping`: repaint fills, strokes, labels, backgrounds, and emphasis marks to the confirmed deck palette, defaulting to the 中智 blue / pale-blue / white / charcoal / small orange-red system.

## QA Checks

A slide fails if:

- It uses a template shape but the placement of report content has no analytical meaning.
- It copies the template's placeholder words, icons, logo, QR code, instructional page elements, or copyright content.
- It forces a source paragraph into a module whose logic does not fit, such as using a cycle for a static three-part classification.
- It preserves the template's original colors, gradients, or accent balance instead of remapping them to the confirmed deck palette.
- It uses 页面整理库 in a way that changes the deck's blue consulting style or introduces colorful generic infographic decoration.
