# 中智咨询字体与配色规范

本规范适用于 mck-ppt-design 的所有新生成材料，替代上游字体与配色默认值。
数值配置为 [ciic-palette.json](ciic-palette.json)，用户原图为 [ciic-color-reference.png](ciic-color-reference.png)。

## 字体

全部文字使用微软雅黑，字体族 `Microsoft YaHei`。覆盖中文、英文、数字、标题、正文、页码、脚注、图表、表格、备注及主题字体。字重通过加粗控制。不得以 Microsoft YaHei UI、Georgia、Arial、KaiTi、SimSun 替代。
既有字号层级保留；字体变更后重新检查换行与溢出。
本机正版字体位于 Microsoft PowerPoint 的 Resources/DFonts/msyh.ttc、msyhbd.ttc、msyhl.ttc；不将字体二进制打包进技能。渲染工具找不到字体时应配置字体路径，不得默默回退。

主蓝的 CMYK 标注作为印刷参考，PPTX 的屏幕配色使用明确 RGB 数值。

## 搭配及检查

默认白底，以蓝色和灰色组成双色搭配。多组数据按图表色 1 至 6 排序；橙色 0 不进入默认系列顺序。相邻浅蓝系列需要白色分隔、清晰标签或图例，不能只靠近似色辨识。
浅底用深灰字，主蓝底用白字。避免浅灰底白字、深蓝底近似蓝字，以及亮度接近的文字与背景组合。正文对比度至少 4.5:1，大字（18pt 以上或 14pt 以上加粗）至少 3:1，此阈值是对原图禁忌的实施细化，原图未指定数值。
`ACCENT_GREEN` 等旧 API 名称仅为兼容别名，不代表允许绿色。需表达达标/风险/滞后时使用文字、符号和规定色值。

主题和所有文字在保存时统一，未列入色板的原生对象颜色直接报错。最终执行 S4 检查；品牌错误没有豁免。自动检查无法替代照片、图片内文字及复杂叠加的目视检查。

维护后验证：使用本机配置的 Python 运行 `scripts/test_ciic_brand.py`，检查可编辑对象、字体归一、非法色拦截与最终检查的独立拦截能力。
