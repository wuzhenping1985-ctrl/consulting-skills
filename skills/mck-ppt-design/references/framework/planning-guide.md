# Presentation Planning Guide

> 框架级规范。版式选择、内容密度和结构规划。

## 原文结构优先

以下页数和版式仅供无既定框架时参考。源文已有层级时，严格保留每层同级项数、顺序和父子关系，不套用参考结构重新归类；正文用完整、清楚的表达，版面不足时调整容器或保留层级续页。逐项结构核对与独立读图审稿都须通过。

## Standard Slide Structures

### 标准汇报（10–12 页）

```
Slide 1:  封面 (cover)
Slide 2:  目录 (toc)
Slide 3:  执行摘要 / 核心论点 (executive_summary 或按原文关系绘制的原生图解)
Slides 4-7: 支撑论证（每页一个论点，变换版式）
Slides 8-10: 案例/证据 (case_study 或 side_by_side)
Slide 11: 综合/路线图 (timeline 或 process_chevron)
Slide 12: 关键结论 + 结束 (key_takeaway 或 closing)
```

### 简短汇报（6–8 页）

```
Slide 1:  封面
Slide 2:  执行摘要 (executive_summary)
Slides 3-5: 核心内容（按原文关系选择数据图、开放构图或原生关系图）
Slide 6:  综合/时间轴
Slide 7:  关键结论
Slide 8:  结束页
```

### 关键规则

- **最少 8 页**（实质性主题）
- **一次性生成全部**：不允许生成后截断
- **目录必须列出所有章节**

## Layout Selection Rules

### 开篇优先级（Slides 2–5 用高影响力版式）

先确定整页轮廓、主要阅读位置及完整原文，再按真实关系选择开放分组、侧弧分支、层叠支撑、路径或其他原生图解。关键数字使用匹配口径的数据图。用户明确要求保留数据表时，可调用表格版式；table_insight不作为观点页首选。

### 数据必须用图表

当内容含有日期/时段 + 数值/百分比时，**必须**用图表版式（#37–#39, #48–#56, #64, #70），不得用文字表格代替。

### 图文版式要求

8页以上 PPT，至少1张使用图文版式（#40–#47, #68）。

### 版式多样性要求

相邻页面的构图由原文关系决定；关系相同可保持一致，关系变化时调整整页结构。不得为轮换图形改变原文层级或添加阶段。

### `two_column_text` 限制

完整正文页可以采用开放图文分区，是否重复由内容关系决定。保持视觉焦点、段距及有作用的留白，不按版式次数判失败。

## 整页构图与阅读要求

1. 保留原文完整文字与各层项目，先确定图形关系与文字位置。
2. 建立视觉焦点与有作用的留白，不设内容占用率、视觉块数或强制底部摘要。
3. 原标题能清楚表达主题时直接沿用，不强制改成判断句或洞见句。
4. 数字按原文口径及阅读需要突出，来源记录与证据保持完整。
5. 实际渲染后分别审查原文、结构与整页艺术构图；占用率及dead_whitespace等诊断仅作提示，不能驱动填满空白或删改文字。
