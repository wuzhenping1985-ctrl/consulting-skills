# 业务文字写作要求

用户明确要求：咨询PPT必须直白、准确，让读者一次看懂。逐页检查标题、正文、表头、图示标签和注释；避免抽象名词堆叠和空泛动词。保留必要政策术语、数字、公式及适用条件。

已确认的改写示例：

- 兼顾全集团经营效益和工资水平约束 → 同时考核集团经营效益，并控制工资水平。
- 人员范围互斥 → 同一人不能重复计入。
- 确认预算边界 → 按核定预算及已批准的调整事项核对。
- 非均匀归属项目另行校正 → 不能按月均摊的工资项目，要另行计算。
- 以可核验历史数据形成认定依据并履行分类程序 → 用历史数据判断竞争类型，按规定认定和备案。

简化文字时逐项对照原文，不能改变达到/低于、可以/必须、原则上/一律等条件；计划人员不能误写为现有人员。标题中的判断必须有正文支持。原文每层有几项，页面该层就保留几项，并维持原顺序和父子关系。完成后先逐项核对原文结构，再由独立审稿者只看渲染页面检查是否自然、完整、易懂；任一审查失败，修正后重审。
